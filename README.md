# Katia Pérez — Links Landing v4

Landing independiente tipo link-in-bio, optimizada para móvil y lista para Netlify.

## Probar localmente

```bash
python -m http.server 5500
```

Abrir `http://localhost:5500`.

## Netlify

No requiere build.
- Build command: dejar vacío
- Publish directory: `.`

Incluye favicon KP, foto de Katia, CTA a PIONER, TikTok, Linktree y bloque oficial de Bucked Up.
